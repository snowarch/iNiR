## Install

```bash
git clone https://github.com/snowarch/inir.git
cd inir
./setup install
```

## Update

```bash
inir update
```

## Families

Plugins from the hub, installed from [inir.space/hub](https://inir.space/hub).

- **Material**: floating bar, sidebars and the Material Design look
- **Waffle**: Windows 11 style taskbar and action center
- **iRiS**: an Island on any screen edge that becomes whatever you open
