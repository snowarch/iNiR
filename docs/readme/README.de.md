## Installation

```bash
git clone https://github.com/snowarch/inir.git
cd inir
./setup install
```

## Aktualisieren

```bash
inir update
```

## Familien

Plugins aus dem Hub, installiert von [inir.space/hub](https://inir.space/hub).

- **Material**: schwebende Leiste, Seitenleisten und der Material-Design-Look
- **Waffle**: Taskbar im Stil von Windows 11 und Aktionscenter
- **iRiS**: eine Insel an jedem Bildschirmrand, die zu dem wird, was du öffnest
