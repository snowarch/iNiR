## Installazione

```bash
git clone https://github.com/snowarch/inir.git
cd inir
./setup install
```

## Aggiornamento

```bash
inir update
```

## Famiglie

Plugin dall'hub, installati da [inir.space/hub](https://inir.space/hub).

- **Material**: barra flottante, pannelli laterali e stile Material Design
- **Waffle**: barra delle applicazioni in stile Windows 11 e centro azioni
- **iRiS**: un'Isola su qualsiasi bordo dello schermo che diventa ciò che apri
