## 설치

```bash
git clone https://github.com/snowarch/inir.git
cd inir
./setup install
```

## 업데이트

```bash
inir update
```

## 패밀리

hub의 플러그인이며, [inir.space/hub](https://inir.space/hub)에서 설치합니다.

- **Material**: 떠 있는 바, 사이드바, Material Design 느낌
- **Waffle**: Windows 11 스타일 작업 표시줄과 작업 센터
- **iRiS**: 화면 가장자리 어디든 놓이는 아일랜드, 여는 것에 따라 모습이 바뀜
