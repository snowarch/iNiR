## Instalação

```bash
git clone https://github.com/snowarch/inir.git
cd inir
./setup install
```

## Atualização

```bash
inir update
```

## Famílias

Plugins do hub, instalados de [inir.space/hub](https://inir.space/hub).

- **Material**: barra flutuante, barras laterais e o visual Material Design
- **Waffle**: barra de tarefas estilo Windows 11 e central de ações
- **iRiS**: uma Ilha em qualquer borda da tela que vira o que você abrir
